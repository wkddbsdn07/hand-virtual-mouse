# 손 가상 마우스

웹캠으로 손과 입모양을 인식해서 마우스와 키보드 없이 Windows를 조작하는 Electron 앱입니다.
모든 인식은 인터넷 없이 이 컴퓨터 안에서 돌아갑니다 (MediaPipe, Whisper).

## 실행

필요한 것: Windows 10/11, 웹캠, 마이크(입모양 입력을 쓸 때), Node.js 20 이상

```sh
npm install   # 의존성 설치 + 손·얼굴 인식 모델 다운로드
npm start
```

앱이 켜지면 바로 손으로 마우스를 조작합니다. 실제 마우스를 쓸 때는 `Ctrl+Alt+M` 으로 일시정지하세요.

## 손 제스처

| 제스처 | 동작 |
|---|---|
| 손 움직이기 | 포인터 이동 (손바닥 중심 기준) |
| 엄지+검지 꼬집기 | 클릭 · 쥔 채 움직이면 드래그 |
| 두 손 꼬집고 벌리기 | 사각형 선택 |
| 엄지+중지 쥐고 위아래 | 스크롤 |
| 엄지+약지 / 엄지+소지 | 복사 / 붙여넣기 |
| ✊ 주먹 쥐고 ← → ↑ ↓ | 창을 왼쪽 반 / 오른쪽 반 / 최대화 / 작게 |
| 🖐🖐 두 손 펴서 벌리기 | 커튼 열기 — 화면 분할 |
| 🖐🖐 두 손 펴서 모으기 | 커튼 닫기 — 바탕화면 보기 |

- 왼손 포인터는 파랑, 오른손은 주황으로 화면에 표시됩니다.
- `C` 키: 지금 손 위치를 화면 중앙으로 맞춥니다 (손을 높이 들지 않아도 되도록).

## 입모양 입력 (`L` 또는 `Ctrl+Alt+L`)

1. 소리 내어 짧은 문장을 말하면 Whisper가 받아써서 입력하고, 그때의 입모양을 그 문장으로 학습합니다.
2. 소리 없이 입만 움직이면 학습한 입모양 중 가장 닮은 문장을 입력합니다.
3. 틀렸으면 6초 안에 ✌(손가락 2개) / 🤟(손가락 3개)로 다른 후보로 고치고, 그 입모양을 다시 학습합니다.

처음 켤 때 음성 인식 모델(약 240MB)을 한 번 내려받습니다. 학습한 입모양은 이 컴퓨터에만 저장됩니다.

## 구조

- `main.js` — Electron 메인 프로세스, 투명 오버레이 창, 단축키
- `native-mouse.js` — PowerShell로 Windows 마우스·키보드 입력을 보냄
- `renderer/modes/` — 손 인식과 가상 마우스 제스처
- `renderer/lip/` — 입모양 특징 추출, 마이크·Whisper, 입모양 학습·인식(DTW)
